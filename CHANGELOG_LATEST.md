# hirecraft v0.1.0

Requisitions, a candidate pipeline, and a scorecard. Local, one SQLite file. Windows x64.

## Downloads

- `hirecraft-app.exe`: the desktop window.
- `hirecraft.exe`: CLI and MCP server.
- `hirecraft-0.1.0-setup.exe`: per-user installer.
- `hirecraft-v0.1.0.mcpb`: MCP bundle.

## What is new

- The window menu is File, Edit, View, Window, and Help.
- Moving a candidate to hired emits `candidate.hired` for contractcraft, teamcraft, and assetcraft.
